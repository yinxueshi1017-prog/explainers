# Deploying this site

Fourteen pages, fourteen preview cards, a sitemap and a robots file. No build step, no
dependencies — the files are served exactly as they are.

**It is already deployed.** GitHub Pages serves `main` from the repository root at
https://yinxueshi1017-prog.github.io/explainers/ . Pushing to `main` publishes; it takes
a minute or two to go live.

## Before you push

```bash
python3 check.py
```

Runs the whole-site gate — the things no single page can see. Size claims
against the real file, every internal link, every `og:image` against a file that exists,
`<title>` inside `<head>`, the disclosure and a contact on every page, the sitemap against
the pages that exist. It exits non-zero on failure. Every check in it exists because
something failed once.

```bash
python3 audit.py
```

The physics, audited from outside the pages. Each piece also checks itself when you open it
with `#dev` — but those checks were written beside the model they check, so a shared mistake
would pass both. `audit.py` reads the constants out of the HTML and compares every central
claim against an independent source (Eurocode 3, Barsom, Faraday, Inglis, Semenov,
Joukowsky, handbook water tables), re-does each closed form numerically, and finishes by
corrupting one constant at a time to prove it can still fail. `#reduce` forces the
reduced-motion path.

## Moving it somewhere else

Any static host works. Cloudflare Pages takes a drag-and-drop of this folder
(dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets) and publishes to
`<project>.pages.dev`. If you move it, the absolute URLs in `sitemap.xml`, `robots.txt`
and every page's `canonical` / `og:url` / `og:image` all name the old origin — change
`BASE` in `check.py` first and let the gate find them.

A custom domain is not needed to launch, and is one field in the host's dashboard later.

## What has to stay true

- **No build step.** Files are served exactly as they are. Do not add a bundler.
- **`hydrogen-embrittlement.html` makes zero network requests.** Verified: the only
  request when loading it is the document itself. If a future edit adds a font, a CDN
  script, or an analytics tag, the claim printed on the page becomes false — either
  remove the request or remove the claim.
- **Relative links only.** The pages link to each other by filename. Do not reintroduce
  absolute `claude.ai/code/artifact/...` URLs — those point at old builds, including one
  that still contains the torque mark.
- **Every explainer runs its own physics checks on load** and warns to the console if they
  fail. `#dev` prints them on the page; `#reduce` forces the reduced-motion path. If a
  future edit breaks the model, the page will tell you — check the console after changing
  it. Each suite includes a negative control that deliberately breaks the model, so a
  suite that has stopped measuring anything cannot pass quietly.
- **Every page carries its own "what is not verified" section.** The index says each page
  does. Keep that true: if you add a piece, it needs one before it goes up.
- **Every page carries a contact.** The whole revenue path is someone reading a piece and
  emailing you; a page without a way to reply is a dead end.
- **The site is pinned dark.** No page follows `prefers-color-scheme` any more. The
  hydrogen piece is a dark instrument panel by brief and does not invert, so the pages
  around it must not either. Each page keeps a light palette under `@media print`, because
  print dialogs drop CSS backgrounds and would otherwise leave pale ink on white paper.
  If you add a page: dark by default, light for print, no OS-preference branch.

## The preview cards

Every page carries Open Graph and Twitter tags and a 1200x630 PNG in `og/`, because a
pasted link otherwise renders as a bare grey URL — on a site whose distribution is people
forwarding pieces to colleagues.

- **`og:image` must be a real raster file at an absolute URL.** Crawlers do not fetch
  `data:` URIs and most reject SVG. This costs the pages nothing: the crawler that unfurls
  the link fetches the card, the reader's browser never does, and every page still loads
  zero off-origin resources.
- **The name on the card, in the unfurl and in the tab is one name.** They may differ in
  case, never in substance — the title and the image are rendered together in an unfurl,
  where a disagreement is visible in a single box. The gate asserts this.
- The cards are generated by a canvas that measures every line before it writes the PNG;
  the generator refuses to produce one that overflows. If you add a piece, draw its card
  the same way rather than by eye.

## Fonts

`the-bolt-that-was-fine.html` used to pull IBM Plex from `fonts.googleapis.com` — three
external requests on a page that argues for making none. The five faces the page actually
sets are now embedded as base64 woff2 (latin subsets): Sans Condensed 600/700, Sans 400,
Mono 400/500. The page costs ~88 KB more and asks nothing of a third party.

IBM Plex is (c) 2017 IBM Corp under the SIL Open Font License 1.1. `LICENSE-IBM-Plex.txt`
ships beside the pages because the OFL requires the licence to travel with the fonts —
**do not delete it.**

If you ever add a weight to that page, embed the matching face too. A weight with no face
is silently faux-bolded by the browser, which looks wrong at headline sizes and gives no
error.

## No external requests anywhere

Verified on the live origin: every page loads zero off-origin resources. If you add
anything that fetches — a font, a script, an analytics tag, an embedded video — either
remove it or remove the claim from the pages, because the claim is printed on them.
